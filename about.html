About Me

Background

My name is Demetre Imedadze, based in Tbilisi, Georgia. My interest in technology began with curiosity about how websites and digital products function behind the scenes. This curiosity quickly turned into a dedicated commitment to study computer science and software development.

Throughout my academic and independent studies, I have prioritized understanding computer science fundamentals, data structures, and web technologies. I believe that writing clean, standard-compliant code is essential for creating accessible digital experiences for everyone.

Learning Journey

My web development journey started with mastering the core building blocks of the web:

  1. 1
    Semantic HTML & Web Standards

    Structuring documents meaningfully using semantic tags (<header>, <nav>, <article>, <section>, <footer>), ensuring high accessibility (a11y) and SEO.

  2. 2
    Styling & Layout Concepts

    Exploring modern CSS layouts, responsive design, Flexbox, and Grid systems to turn structured content into visually engaging interfaces.

  3. 3
    Logic & Interactivity

    Diving into JavaScript to build interactive components, manipulate the DOM, and handle client-side state dynamically.

  4. 4
    Tools & Version Control

    Using Git and GitHub for tracking code changes, branching, and collaborating on software repositories.
